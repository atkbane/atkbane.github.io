# 🧰 Herramientas de Ingeniería Hidráulica

Portafolio web de herramientas de cálculo y diseño para estructuras hidráulicas. Todas las aplicaciones ejecutan Python en el navegador con [Pyodide](https://pyodide.org/) — sin instalación, sin servidor.

---

## 🌐 Herramientas disponibles

| Herramienta | Descripción | Enlace |
|-------------|-------------|--------|
| **Vaciado de Desarenador** | Simulación del vaciado de un desarenador rectangular. Orificio → vertedero con sigmoide, integración ODE. | [Abrir](https://atkbane.github.io/vaciado_desarenador/) |
| **Pérdida de Carga en Tuberías** | Fricción y pérdidas localizadas en tuberías a presión. Darcy‑Weisbach, Hazen‑Williams, Manning. | [Abrir](https://atkbane.github.io/perdida_de_carga_tuberias/) |
| **Diseño de Desarenador** | Dimensionamiento de naves de sedimentación. Camp, Shields, Zanke. Bisel dinámico. | [Abrir](https://atkbane.github.io/diseno_desarenador/) |
| **Línea de Energía** | Bernoulli encadenado: desarenador → bocatoma. Transiciones, rejillas (Kirschmer), tranquilizadores. | [Abrir](https://atkbane.github.io/linea_de_energia/) |

---

## 🛠️ Tecnologías

- [Pyodide](https://pyodide.org/) — Python en el navegador vía WebAssembly
- [Plotly](https://plotly.com/) — Gráficos interactivos (vaciado)
- HTML5, CSS3, JavaScript vanilla
